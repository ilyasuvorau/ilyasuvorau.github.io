Privacy policy

Last updated: September 30, 2026

Failure Files Analytics ("the app") is a private tool used only by the owner of the YouTube channel Failure Files. It is not offered to other users.

What the app accesses

  • YouTube Analytics data of the owner's own channel (scope yt-analytics.readonly): views, watch time, audience retention, traffic sources, subscribers gained.
  • The list of the owner's own uploaded videos (scope youtube.readonly), to match video IDs to titles.

Access is read-only. The app cannot upload, edit, delete or publish anything, and it does not access any other channel or any personal data of viewers.

How the data is used and stored

The data is used only to produce metric summaries for the channel owner (in the terminal and in a private Telegram chat). The OAuth token is stored only in the owner's local configuration and in the owner's private CI secrets. No data is sold, shared with third parties or used for advertising.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
